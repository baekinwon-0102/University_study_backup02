HOG
- 다랄과 트릭스는 사람이 서 있는 영상에서 그래디언트를 구함
- 그래디언트의 크기와 방향 성분을 이용해 사람이 서 있는 형태에 대한 특징 벡터를 정의
- 머신 러닝의 일종인 서포트 벡터 머신 알고리즘을 이용해 입력 영상에서 보행자 위치를
  검출하는 방법 제안(2005)

그래디언트 ※ 퀴즈 나올 듯?
- 수평/수직으로 픽셀의 데이터의 변화량을 계측
- 우측 커널을 사용하면 쉽게 얻을 수 있음
- Sobel 연산을 통해 계산 가능
- 100  100   100
   50    50    50
   200  200  200           이고 그래디언트가 -1 0 1  이면
  가로축 그래디언트는 -100 + 0 + 100 = 0 모두 0이고
   세로는 -100 + 0 + 200 = 100 모두 100이 될 것임

HOG 알고리즘과 보행자 검출
- 다랄과 트릭스는 수천 장의 보행자 영상과 보행자가 아닌 영상에서 HOG 특징 벡터를 추출
- 이 두 특징 벡터를 구분 위해 SVM 알고리즘 사용
- 다랄과 트릭스는 수천 개의 보행자 특징 벡터와 보행자가 아닌 특징 벡터를 이용해
  SVM을 훈련시켜 효과적인 보행자 검출 방법 완성
- HOG와 SVM을 이용한 객체 검출 기술은 이후 보행자 검출뿐 아니라 다양한 형태의
  객체 검출에서도 응용
- OpenCV는 HOG 알고리즘 구현한 HOGDescriptor 클래스 제공
- HOGDescriptor 클래스를 이용하면 특정 객체의 HOG 기술자를 쉽게 구할 수 있음
- HOGDescriptor 클래스는 보행자 검출 위한 용도로 미리 계산된 HOG 기술자 정보 제공

GoogLeNet 영상 인식
- 구글넷은 이름에서 알 수 있듯이 구글에서 발표한 네트워크 구조임
- 2014년 ILSVRC 영상 인식 분야에서 1위
- 딥러닝 네트워크 구조 중에서 가장 많은 레이어를 사용한 형태
- 레이어를 매우 깊게 설계하였지만 완전 연결 레이어가 없는 구조를 통해 기존의
  다른 네트워크보다 파라미터 수가 훨씬 적은 것이 특징
- 구글넷은 특히 다양한 크기의 커널을 한꺼번에 사용해 영상에서 큰 특징과 작은 특징을
  모두 추출할 수 있도록 설계됨
- 인식 기능 사용하려면 다른 딥러닝 프레임워크를 이용해 미리 훈련된 모델 파일과
  구성 파일 필요

Object Detection 알고리즘의 역사
- CNN -> R-CNN -> Fast R-CNN -> Faster R-CNN -> YOLO
- 뒤로 갈 수록 서로간의 장점을 흡수해 성능 향상

You only look once(YOLO)
- 80개의 서로 다른 객체 인식
- 정확도를 유지하면서 고속으로 연산 가능한 것이 장점
- Selective Search/Sliding window의 단점 극복
- OpenCV를 사용하면 CPU 기반에서 속도 향상 가능
- Python 등의 다양한 인터페이스로 접근 가능

cvlib
- Python 기반
- Example Code 제공
- 컴퓨터 비전 라이브러리를 간단하고 쉽게 사용 가능
- 기능에 맞는 Network들이 이미 선정되어 있고, 자동 다운로드 Script 존재
- 기능
  - 얼굴 인식
  - 성별 인식
  - 물체 검출
- 입력/출력
  - 웹캠
  - 이미지
  - 비디오

cvlib 얼굴 인식
- OpenCV의 dnn 모듈을 사용
- 사전 학습된 Caffe 모델 사용
- SSD 알고리즘 사용

cvlib 성별 인식
- 사전 학습된 Caffe 모델 사용
- 얼굴 인식을 먼저 하고, 이후 Crop된 영상에서 성별 확인

cvlib 물체 검출
- OpenCV의 dnn 모듈을 사용
- 사전 학습된 DarkNet 모델 사용
- YOLO 알고리즘 사용

ultralytics
- 객체탐지 알고리즘
- 실시간 컴퓨터비전 시리즈를 개발, 유지보수하는 오픈소스 AI 기업 및 통합 Python 프레임
  워크
- 이미지, 영상 데이터의 전처리부터 모델 학습, 검증, 추론, 경량화 및 배포까지 단 몇 줄의
  코드나 CLI 명령어로 처리할 수 있는 통합 파이프라인을 제공
- 과거 널리 쓰인 YOLOv5, YOLOv8, YOLO11을 거쳐, 네이티브 엔드투엔드 추론과
  엣지 환경 최적화를 도입한 최신 YOLO26 모델군까지 단일 패키지로 지원
