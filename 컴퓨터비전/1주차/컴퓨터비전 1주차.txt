영상처리
- 입력된 영상을 어떤 목적을 위해 처리하는 기술
- 어떤 목적을 위해 수학적 연산을 이용해 화소들에 대해 변화 주는 것
- 아날로그 영상 처리 / 디지털 영상 처리

화소
- 영상의 구성요소
- 픽셀은 사직과 요소를 뜻하는 영단어로부터 유래
- 카메라 스펙을 나타내는 용어 중 2000만 화소라는 말은 2000만 개의 픽셀로 이루어진 사진
  촬영할 수 있음을 의미

화소 처리
- 영상 처리의 출발점

영상
- 밝기와 색상이 다른 일정한 수의 화소들로 구성

저수준 영상처리
- 영상 처리 결과가 영상인 경우

고수준 영상처리
- 영상 처리 결과가 영상이 아니라, 영상의 특성을 나타내는 경우

영상 처리의 시작
- 1920년 초 런던과 뉴욕 간 해저 케이블 통한 신문사들이 사진 전송

본격적인 영상 처리 위한 기술
- 1940년대 폰 노이만의 디지털 컴퓨터 개념 시작
- 1950년 이후 트랜지스터, IC, 마이크로프로세서 같은 하드웨어 발달
- 1950~1960년대 프로그램의 언어 발달과 운영체제 등의 소프트웨어 기술 발달

본격적인 영상 처리 시작
- 우주 탐사 계획인 아폴로 계획과도 관련, 우주선에서 보낸 훼손된 영상의 복원 연구

1970년대 영상 처리 분야 더욱 발전
- CT, MRI 등의 의료 분야
- 원격 자원 탐사, 우주 항공 관련 분야

1990년대 컴퓨터 비전과 응용 분야 급속히 확장
- 인터넷 시대에 영상검색, 영상전송, 영상광고
- 디지털 방송 관련 컴퓨터 그래픽스, 디지털 카메라 보급

컴퓨터 비전
- 컴퓨터에게 시각 데이터 처리 능력을 부여하는 기술
 - 카메라와 센서: 눈
 - 컴퓨터 비전: 뇌

활용
- 사람의 얼굴을 인식해 신원 데이터 조회
- 야생동물의 이동경로 추적
- 원격 수술과 의료 영상 분석
- HDR(High Dynamic Range) 사진 촬영
- 인스타그램의 필터
 - 영상의 화질 개선해 보기 좋은 사진 만드는 용도

머신 비전
- 공장에서는 제품 검사, 측정, 불량 판정 등의 목적으로 컴퓨터 비전 활용하는 것
- 사람의 수작업 대체하며, 사람보다 훨씬 빠르고 정확하게 동작해 공장 자동화에 주로 사용
- 컴퓨터 비전은 앞으로도 더 많은 영역에서 사용성이 더 높아짐

영상 처리 활용 분야
- 영상 처리
  - 입력 영상을 처리해 출력으로 처리된 영상 획득
- 컴퓨터 비전
  - 입력은 영상, 출력은 어떤 정보
  - 얼굴인식, 지문 인식, 번호판 인식 등
- 컴퓨터 그래픽스
  - 입력이 어떤 서술이고, 출력이 영상
  - CAD 프로그램
     - 그리고자 하는 물체의 수치 입력
     - 해당 물체의 그래픽 영상 생성

파장과 빛의 특성 -> OX 퀴즈 나옴
- 파장에 따른 빛의 종류
  - 가시 광선 영역은 매우 좁음
  - 파장이 짧을수록 에너지 큼

태양에서 오는 빛의 세기 -> OX 퀴즈 나옴
- 가시광선 영역이 가장 많음
- 자연에 존재하는 수증기, 이산화탄소, 산소 등에 흡수되어 양의 변화가 고르지 못함

영상의 획득과 표현 방법
- 피사체
  - 카메라로 사진 찍을 때, 그 대상이 되는 풍경이나 사물
- 렌즈
  - 카메라 바깥으로부터 들어온 빛을 굴절시켜 이미지 센서로 모아 주는 부품
- 이미지 센서
  - 빛을 전기적 신호로 변환하는 포토 다이오드가 2차원 평면상에 배열되어 있는 장치
- 태양의 가시광선 또는 특정 광원에서 발생한 빛이 피사체에 부딪혀 반사되고, 그 반사된
  빛이 카메라 렌즈를 통해 카메라 내부로 들어오게 됨
- 렌즈에서 모인 빛이 이미지 센서에 닿으면 이미지 센서에 포함된 포토 다이오드가 빛을
  전기적 신호로 변환
- 빛을 많이 받은 포토 다이오드는 큰 신호를 생성하고, 빛을 적게 받은 포토 다이오드는
  작은 크기의 신호를 생성함으로써 명암이 있는 2차원 영상 구성
- 포토 다이오드에서 생성된 전기적 신호는 아날로그-디지털 변환기를 거쳐 디지털
  신호로 바뀌게 됨
- 이 디지털 신호는 다시 카메라의 ISP 장치로 전달
- ISP 장치는 화이트밸런스 조정, 색 보정, 잡음 제거 등의 기본적 처리를 수행한 후 2차원
  영상을 생성함
- 구성된 영상은 곧바로 컴퓨터로 전송되거나 또는 JPG, TIFF 등의 영상 파일 형식으로 변환
  되어 저장

영상 형성 과정
- 위치 값과 밝기 값을 가진 일정한 수의 화소들 모임이 영상
- 하나의 픽셀은 하나의 밝기 또는 색상을 표현

양자화
- 제한된 비트수로 화소값을 나타내려 밝기 값을 정수화 시키는 과정

샘플링
- 무한한 연속된 값을 질정한 해상도에 따라 유한개의 화소수만큼 입력 값을 취하는 과정

화소와 디지털 영상
- 픽셀 모여서 2차원 영상 구성
- 영상은 픽셀이 바둑판처럼 균일한 격자 형태로 배열되어 있는 형태
- 좌표의 시작을 0부터 표현하는 방식을 0기반 표현이라고 부르며, 보통 많이 사용

MxN 크기 디지털 영상
- 표본화 수에 따라 M,N 결정
- 양자화 수준에 따라 밝기 값 레벨 결정
 - k 비트로 양자화 -> 2^k개 레벨
 - 8비트 양자화 -> 28개 = 256개 레벨

그레이 스케일 영상
- 2차원 영상을 흑색과 백색 사이의 색으로 구분
- 영상에서 밝은 영역의 픽셀은 큰 그레이스케일 값을 가지고, 어두운 영역의 픽셀은 
  상대적으로 작은 그레이 스케일 값 가짐

컬러 영상
- 트루컬러 영상은 보통 R,G,B 세 개의 색상 성분 조합으로 픽셀 값 표현
- 여기서 R은 빨간색, G는 녹색, B는 파란색을 나타냄
- 각각의 색상 성분은 0부터 255 사이 정수 값 표현
- 0은 해당 색상 성분이 전혀 없음 의미, 255는 해당 색상 성분 가득차 있음을 의미
- 트루컬러 영상에서 하나의 픽셀은 unsigned char 자료형 세 개를 이용해 표현 가능
- R,G,B 색상 성분의 조합으로 표현할 수 있는 대표적인 색과 색상 성분 값을 나타냄
