이미지 파일 처리 주요 함수
- cv.imread(filename[,flags]) -> retval
  - 파일에서 이미지 읽어오는 함수
  - filename: 파일 이름
  - flags: 색상 유형 결정하는 flag
- cv.imwrite(filename, img[,params]) -> retval
  - 이미지를 특정 파일에 저장하는 함수
  - filename: 저장할 파일 이름
  - img: 저장하고자 하는 이미지
  - flags: 압축 방식을 결정하는 flag

색상 유형 결정 상수
- cv2.IMREAD_**
  - UNCHANGED: 입력 파일에 정의된 타입 그대로 반환
  - GRAYSCALE: 명암도 영상으로 변환
  - COLOR: 컬러 영상으로 변환
  - ANYDEPTH: 정의된 깊이에 따라 16비트/32비트 영상으로 변환(0~255)
  - ANYCOLOR: 입력 파일에 정의된 타입의 영상 반환

bmp
- 가장 처음 만들어진 이미지 확장자
- 저장공간에도 픽셀의 채널을 그대로 저장함
- 있는 그대로 8비트씩 저장함

JPG
- 픽셀의 채널 값이 서로서로 차이가 잘 안 나면 통일시켜서 개수를 셈
- 정보 손실이 좀 있음
- 디지털 풍화 효과가 있음

PNG
- 압축을 하긴 하는데, 정보가 손실 안 되도록 함
- 비슷한게 아니라 똑같은 채널 값을 통일 시킴
- 디지털 풍화가 없어서 영상 분석의 기본 확장자임

imwrite() 사용 함수
- IMWRITE_JEPG_QUALITY
  - JPG 파일 화질, 높은 값일수록 화질 좋음
- PNG_COMPRESSION: PNG 압룩 레벨
- PXM_BINARY: PPM, PGM 파일의 이진 포멧 설정

동영상 파일
- 초당 30프레임 저장, 압축 필요 시 -> 압축 코덱 사용
- OpenCV는 동영상을 처리할 수 있는 클래스 제공
  - cv2.VideoCapture()
  - filename, device: 개방할 동영상 캡처 장치의 ID(카메라 한대만 연결되면 0을 지정)
  - cv2.VideoCapture.get(propid) -> retval
  - 비디오 캡처의 속성 식별자로 지정된 속성 값 반환
  - propid: 속성 식별자
  - cv2.VideoCapture.set(propid, value)
  - 지정된 속성 식별자로 비디오 캡처의 속성 설정
  - 1000/frame_rate -> 필요 대기시간

cv2.VideoWriter([filename, fourcc,fps,frameSize[,isColor]])
- fourcc: 프레임 압축에 사용되는 코덱의 4-문자
- fps: 생성된 동영상 프레임들의 프레임률
- frameSize: 동영상 프레임 크기
- isColor: True면 컬러 프레임으로 인코딩, False면 명암도 프레임으로 인코딩

파이썬에서 배열
- 1차원: 벡터
- 2차원: 행렬
- 1차원과 2차원 데이터 통칭: 배열

cv.flip(src, flipCode[,dst]): 입력된 2차원 배열 뒤집기
- flipCode: 배열 뒤집는 축, 0이면 위아래, 1이면 좌우, -1이면 양축 기준

cv2.repeat(src,ny,nx[dst]): 입력 배열의 반복된 복사본으로 출력 배열 채우기
- ny,nx: 수직, 수평방향 반복 횟수

cv2.transpose(src[,dst]): 입력 행렬의 전치 행렬을 출력으로 반환

채널의 개념
- 3채널 넘파이 배열이 기본
- 첫번째 배열은 세로축, 2번째 배열은 가로축, 3번째 배열은 색상을 뜻함 
- 한개의 벡터가 한 픽셀임

cv2.merge(mv[,dst])): 여러 개 단일 채널 배열을 다채널 배열로 합성
- mv: 합성될 입력 배열 혹은 벡터, 합성될 단일채널 배열들의 크기와 깊이가 동일해야 함

cv2.split(m[,mv]): 다채널 배열을 여러 개의 단일채널 배열로 분리
- m: 입력되는 다채널 배열
- mv: 분리되어 반환되는 단일채널 배열들 벡터

opencv와 numpy 차이점
- cv2는 x, y / numpy는 y,x 임
