통신방식
- 간단한 데이터만 주고 받을 때는 GPIO로도 충분하지만,
빠른 성능 및 다량의 신호 전달 위해선 통신 프로토콜 사용

병렬 통신
- 장치간 바이트 단위로 data 송수신하는 통신
(한 번에 바이트 단위로 전송)
- 통신 속도 상대적으로 빠름
클럭당 전송되는 비트 수: 통신선로 개수 만큼
- 양단간 통신거리가 가까운 경우에 사용가능
- 구현이 어렵고 비용이 증가

직렬 통신
- 장치간에 비트 단위로 data 송수신하는 통신
(한 번에 한 비트씩 순차적으로 전송)
- 양단간 통신거리가 먼 경우 사용 용이
- 구현이 상대적으로 쉬움

비동기식
- 동기신호 없이 데이터 신호만을 보내고 각각의 방식으로 데이터 비트
찾아내는 방식(전송할 데이터 있을 때 start bit를 보낸 후 데이터를
보내고, 마지막에 stop bit를 전송)
- 통신속도가 상대적으로 느림
- 구현이 단순, 저가

동기식
- 데이터 신호와는 별도로 동기신호(클럭 신호)를 함께 보내는 방식
(클럭 신호를 이용해 데이터 전송 타이밍을 맞추는 방식)
- 통신 속도가 빠름
- 구현이 복잡, 고가

전이중 통신방식
- 두 장치간 통신선이 두 개(송신성, 수신선)
- 데이터 송신과 수신이 동시에 가능

반이중 통신방식
- 두 장치간 통신선이 하나만 존재
- 하나의 통신선으로 송신과 수신을 해야 함
송신과 수신 동시에 불가능(한쪽이 송신시 다른 상대방은 수신만 가능)

I2C통신: TWI(Two Wire Interface) ★ 시험에 나옴
- 라즈베리파이에 사용되는 센서 또는 모듈과의 데이터 송수신에 많이 사용
- 구성: Master/Slave구조 - 하나의 Master와 하나 이상의 Slave(1:N)
- 2개 핀으로 통신이 가능(SDA, SCL)
SDA(데이터): Master와 Slave간 데이터를 주고 받기 위한 선(데이터선 공유 -> 반이중통신)
SCL(동기클럭): 데이터 송수신시 타이밍을 동기화 하기 위한 클럭 선

LCD 통신방식
- I2C 통신 방식
- 동기식, 반이중 직렬 통신 버스(Master/Slave 구조)

캐릭터 LCD(Character Liquid Crystal Display)
- 캐릭터 LCD는 문자를 출력하기 알맞게 제작된 액정 디스플레이 모듈

LCD1602
- 16개의 글자를 두 줄에 출력할 수 있는 표시 장치

가변저항기
- 회전량 만큼의 저항값 변화 -> LCD 밝기 및 선명도 조절

python requests 모듈
- requests 모듈은 Python용 HTTP 라이브러리
- HTTP 요청을 보내고 응답을 받는데 사용되는 라이브러리
- 특정 웹사이트에 접속해 페이지의 HTML 소스코드를 받아서 필요한 정보 추출 시 사용
