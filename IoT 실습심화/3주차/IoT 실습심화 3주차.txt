RGB LED
- 제품 타입 2가지
  - 긴 다리를 GND에 연결하는 공통 캐소드 타입
  - 5V나 3.3V에 연결하는 공통 애노드 타입

PWM
- 디지털 신호를 이용해 아날로그 회로처럼 제어하는 방법
- 펄스 폭을 조정해 LED의 밝기와 서보모터의 방향 제어

Duty Cycle
- Pulse Width / 주기 *100

PWM 사용법
- gezogpio RGBLED 클래스는 기본적으로 PWM 기능 내장
- 디지털 출력 쪼개는 소프트웨어 PWM 기술 활용해 구동

gpiozero 라이브러리의 RGBLED 클래스 이용
- RGBLED 모듈을 쉽게 제어할 수 있도록 만든 전용 도구
- 핵심 제어 수단: color 속성(Property)
- 기본적으로 softPWM으로 동작 전류의 양을 미세 조정해 밝기 조절

rgb.color = (값)
- 함수로 호출하는 것이 아니라, 일반 변수처럼 값을 직접 읽거나 바꿀 수 있도록 설계

★중간고사 출제
- RGB 동작회로 구성
  - GPIO 17 > RED
  - GPIO 27 > BLUE
  - GPIO 22 > GREEN
- RGB LED ON/OFF 제어 코딩
