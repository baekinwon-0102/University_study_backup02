IoT 센서 데이터 처리 과정
- 센서 데이터 수집 -> 센서 데이터 추출 -> 센서데이터 처리 -> 센서데이터 활용
- 수집: 원시 데이터 수집, 파일 형태로 저장
- 추출: 원시데이터 추출, 파일 입출력
- 처리: 원시데이터를 원하는 정보로 변환처리
- 활용: 웹서버 구축, 실시간 모니터링, 자동화 시스템 구축

센서
- 감각하여 알아내는 장치

액추에이터
- 시스템을 움직이거나 제어하는 기계장치

1-wire 통신
- 하나의 데이터 버스로 송/수신이 가능한 통신 방식
- 비동기방식(클럭 없음), 반이중 직렬통신(data line이 1개)
- I2C 버스: SDA(data), SCL(clock), 2핀이 필요(LCD 연결) -> 동기식, 반이중
- 1-wire 버스: data 1핀 필요(온도센서) -> 비동기식, 반이중 직렬 통신

온도센서(DS18B20)
- GPIO를 제어해 1-wire 통신으로 온도 측정할 수 있는 디지털 온도계 모듈
- 소자마다 고유한 64비트 일련번호 새겨짐

풀업저항
- 플로팅 현상 방지
- 플로팅 현상: 스위치가 연결되지 않은 상태에서 전류가 흐르는지 흐르지 않는지 알 수 없는 상태
  즉, HIGH인지 LOW인지 불안정한 상태(주변 노이즈에 민감) -> 저항 연결해 확실히 HIGH 상태로 만듬
