Flask
- 파이썬 기반 마이크로 웹 프레임워크
- django는 파이썬 기반 풀 웹 프레임워크

웹 프레임워크
- 웹 애플리케이션 개발을 쉽고 빠르게 할 수 있도록 미리 만들어진 구조와 도구를 제공하는
  소프트웨어
- Flask는 기본적으로 HTTP 프로토콜 사용, HTTP는 TCP를 기반으로 동작

Flask 라우팅
- 특정 URL 요청 들어왔을 때 해당 함수 실행되도록 URL과 실행 함수 지정하는 역할

GET
- 리소스 얻어 오기 위한 요청
- 바디 사용 없이 URL에 쿼리 스트링으로 파라미터 데이터 전달

POST
- 새로운 리소스 생성 위한 요청
- 바디를 사용해 파라미터 데이터 전달

Jinja2(Flask 템플릿엔진)
- 템플릿으로 파이썬 로직 코드와 HTML 화면 디자인을 서로 분리해 관리
  - 파이썬 파일에는 데이터 처리나 하드웨어 제어 로직만 남기고, HTML 파일은 별도 관리
- 템플릿 엔진을 통해 동적 웹페이지 제공
  - 정적 웹페이지: 서버에 미리 저장된 HTML 파일을 그대로 사용자에게 보여줌
  - 동적 웹페이지: 사용자의 요청, 시간, DB의 상태에 따라 실시간으로 HTML을 만들어 제공
  
Jinja2 사용법
- 템플릿: 사용자에게 보여줄 HTML 틀
- Jinja2: HTML 코드안에서 파이썬 문법(변수, 반복문 등)을 결합해 동적 HTML 문서를 
  만들어주는 Flask 템플릿 엔진

SSR 방식
- 서버가 데이터가 반영된 완선된 HTML 페이지를 만들어서 브라우저에 전달
- GET 방식 사용

CSR 방식
- 클라이언트가 웹 화면을 직접 만드는 방식
