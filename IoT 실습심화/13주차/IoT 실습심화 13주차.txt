코드 통합
- 소프트웨어 개발 과정에서 여러 소스 코드 파일을 하나의 메인 프로젝트 코드로 병합해
  실행 가능한 전체 애플리케이션 구현하는 작업

스마트 센서 제어 시스템
- 센서로 주변 환경 실시간 감지 후 데이터를 분석, 판단해 소자를 자동으로 제어하고
  사용자에게 상태 알리는 지능형 자동화 시스템

라즈베리파이 카메라
- 라즈베리파이 3 혹은 4의 경우 HDMI 포트 옆 카메라 인터페이스에 22핀 케이블 이용
- 파이 카메라 모듈은 라즈베리파이를 지원하는 휴대용 경량 카메라

카메라 제어 방식
- 라즈베리파이 OS Bookworm(Trixie 이전버전) 부터는 기존의 picamera 라이브러리 중단
- 새로운 picamera2 라이브러리와 libcamera 카메라 스택으로 대체
- 카메라 초기 상태에서 Enable로 설정
- 필요한 라이브러리는 이미 설치되어 있음

스마트 카메라 '웹 캠'  서비스
- 라즈베리파이 웹 캠은 Flask를 사용해 라즈베리파이 웹 서버를 구축하고,
  파이 카메라 영상을 웹 브라우저로 실시간 스트리밍하는 기술

generator_frames()
- 웹으로 실시간 카메라 영상을 스트리밍할 때 사용하는 사용자 정의 제너레이터 함수
- 대용량 파일 다운로드나 실시간 데이터 전송 등 응답 본문을 청크 단위로 나누어 보내야
  하는 스트리밍 응답을 구현할 때
  -> 제너레이터 함수와 Response 같이 사용
